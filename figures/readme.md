# Figures and Visualizations

This directory stores visual outputs generated during exploratory data analysis and ANN model evaluation.

## 1. Distribution Analysis

Folder: `distribution_analysis/`

Contains visualizations examining the distribution of temperature values across different CFD operating conditions.

Expected outputs:
- Temperature histograms
- Kernel density estimation (KDE) plots
- Box plots comparing simulation cases

## 2. Parameter Sensitivity

Folder: `parameter_sensitivity/`

Contains plots investigating how temperature behaviour changes with:
- Peclet number (Pe)
- Knudsen number (Kn)
- Tangential momentum accommodation coefficient (TMAC)

## 3. Correlation Analysis

Folder: `correlation_analysis/`

Contains correlation visualizations used to investigate relationships between input parameters, spatial features and temperature.

## 4. Model Evaluation

Folder: `model_evaluation/`

Contains visual comparisons of ANN predictions and CFD reference results.

Potential outputs include:
- Predicted versus actual temperature plots
- Prediction error distributions
- Regional temperature-field comparisons
- Model performance comparisons

## Note

The folders organize the intended visualization outputs. Only generated and verified figures should be added. Raw CFD data and model prediction files are maintained separately.
