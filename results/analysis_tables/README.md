# Analysis Tables

This directory stores tabular outputs generated during exploratory data analysis of the microchannel CFD dataset.

## Analysis outputs

The analysis covers:

- **Descriptive statistics:** Temperature statistics across simulation cases and operating conditions.
- **Distribution analysis:** Numerical summaries of temperature distributions.
- **Parameter sensitivity:** Changes in temperature behaviour with Pe, Kn and TMAC.
- **Correlation analysis:** Relationships between model inputs and temperature.
- **Parameter interactions:** Combined effects of Knudsen number and TMAC.

## File formats

Analysis outputs may be stored as:

- CSV files for numerical results.
- Excel workbooks for organized multi-sheet analysis.

## Reproducibility

The analysis tables are generated using the notebook:

`notebooks/01_CFD_Data_Analytics_EDA.ipynb`

The raw CFD simulation dataset is not included in this repository.
